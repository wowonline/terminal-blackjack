# 🃏 terminal-blackjack

Блэкджек в терминале, запускается командой `blackjack`. Большие карты с цветными мастями, управление одной клавишей, подсказки и дилер, который играет оптимально.

```
  ДИЛЕР  10 + ?
  ╭───────╮ ╭───────╮
  │K♠     │ │░░░░░░░│
  │   ♠   │ │░░░░░░░│
  │     K♠│ │░░░░░░░│
  ╰───────╯ ╰───────╯

  ВЫ  7 / 17   ставка 50
  ╭───────╮ ╭───────╮
  │A♥     │ │6♣     │
  │   ♥   │ │   ♣   │
  │     A♥│ │     6♣│
  ╰───────╯ ╰───────╯

  💡 Совет: ЕЩЁ      [T] вид: словами
     оценка: ещё лучший · хватит ошибка · удвоить ошибка
  [H] ещё   [S] хватит   [D] удвоить   [?] совет   [Q] выход
```

## Установка

Нужен Python 3.9+. Зависимостей нет.

С [uv](https://docs.astral.sh/uv/):

```sh
uv tool install git+https://github.com/wowonline/terminal-blackjack
```

или с [pipx](https://pipx.pypa.io/):

```sh
pipx install git+https://github.com/wowonline/terminal-blackjack
```

После этого в `PATH` появится команда `blackjack`. Если терминал её не находит, выполните `uv tool update-shell` (или `pipx ensurepath`) и откройте новое окно.

<details>
<summary>Без uv и pipx: это один файл</summary>

```sh
curl -fsSL https://raw.githubusercontent.com/wowonline/terminal-blackjack/main/blackjack.py -o ~/.local/bin/blackjack
chmod +x ~/.local/bin/blackjack
```

Папка `~/.local/bin` должна быть в `PATH`.
</details>

## Игра

```sh
blackjack                   # умный дилер, 6 колод, банк 1000
blackjack --dealer s17      # дилер по правилам казино
blackjack --hints           # совет на каждом ходу
blackjack --hint-style odds # совет в виде шансов
blackjack --help
```

| Клавиша | Действие |
|---|---|
| `H` | ещё карту |
| `S` | хватит |
| `D` | удвоить ставку и взять одну карту |
| `P` | разделить пару на две руки |
| `?` | совет: какой ход лучше |
| `T` | вид совета: словами, шансы или матожидание |
| `Q` | выход |

Клавиши работают и в русской раскладке. Ставка вводится числом, Enter повторяет прошлую.

### Как читать совет

По `?` игра называет лучший ход и оценивает остальные. Клавиша `T` переключает вид оценки, а при запуске его задаёт флаг `--hint-style`:

- **Словами** (`words`, по умолчанию): «лучший», «тоже ок» (почти не уступает лучшему), «хуже», «ошибка». Сразу видно, важен ли выбор, но без чисел.
- **Шансы** (`odds`): вероятность выиграть раздачу, если сыграть так и дальше играть лучшим образом. Понятнее всего, но не учитывает, сколько стоит на кону: у удвоения и сплита это две ставки, поэтому ход с самым высоким шансом не всегда лучший.
- **Матожидание** (`ev`): сколько фишек ход приносит в среднем при вашей ставке, если сыграть так много раз. Самый точный вид, лучший ход выбирается именно по нему. Минус значит, что в среднем вы теряете. Иногда убыточны все ходы, и совет выбирает тот, где потери меньше.

Например, пара восьмёрок против десятки у умного дилера, ставка 50:

| | ещё | хватит | удвоить | разделить |
|---|---|---|---|---|
| словами | **лучший** | тоже ок | ошибка | хуже |
| шансы | 18% | 16% | 18% | 29% |
| матожидание | −28 | −28 | −56 | −30 |

У сплита самый высокий шанс выиграть, но на кону две ставки, и в среднем он теряет больше, чем «ещё». А то, что «ещё» и «хватит» почти равны, видно только словами или по матожиданию.

### Дилеры

- `smart` (по умолчанию): видит ваши карты, знает, что осталось в шузе, и берёт карту, только когда это ему выгодно. Правила «до 17» у него нет. Даже при идеальной игре вы теряете около 10 % ставки.
- `s17`: как в казино, берёт до 17, на мягких 17 останавливается. Игра почти на равных.
- `h17`: берёт до 17, на мягких 17 (например, туз + 6) берёт ещё.

### Правила

Блэкджек платит 3:2. Дилер сразу проверяет, нет ли у него блэкджека. Удвоить можно на любых двух картах, в том числе после сплита. Сплит до 4 рук, тузы после сплита получают по одной карте. Страховки и сдачи нет.
